polyhexes

a polyhex is a connected set of n cells on the hexagonal tiling, joined edge to edge. counted free: up to rotation and reflection. the counts below are generated right here in the page, then checked against OEIS A000228.

n = 1, 2, 3, 4, 5, 6 → 1, 1, 3, 7, 22, 82. the heptahex count (n=7) is 333; too many to draw all of them here.
