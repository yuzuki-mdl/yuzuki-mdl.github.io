slime mould, six ways

physarum polycephalum has no brain. it solves mazes, picks near-optimal transport networks, and remembers where it's been by leaving a trail of itself. here's everything i built chasing that. each one is a different honest answer to "how does a blob do this?"

physarum — the classic

40,000 agents, each sensing left/right and following the strongest trail. the original. click to drop food, watch the veins form.

physarum maze agents in a maze

the same swarm, but trapped in a generated maze with food at both ends. they only smell, no map — and find their way through.

physarum flow solver the honest model

forget agents. this is the real Tero/Nakagaki model: conductance on each edge rises where flux is high, decays where it isn't. the surviving network contains the shortest path. gamma and decay are the knobs.

physarum with lag

the same flow solver, but each edge reacts to flux from a moment ago. delay changes what the network settles into — it can oscillate, or remember a path it no longer needs.

slime mould network redundant, like the real thing

nodes on open cells, tubes between them. real mould doesn't pick one path — it keeps loops for robustness. this one does too. raise the prune threshold to strip it to the backbone.

slime tsp

the travelling salesman problem, solved by a blob. food sources as cities, the network as the route. it's not exact, but it's weirdly close for something with no neurons.

slime on a hyperbolic surface

what if the mould lived in hyperbolic space, where every point is a saddle? the same rules, a surface that curves away from itself. it still finds a path.
