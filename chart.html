the chart, not the picture

gliders on closed / aperiodic substrates, split by rule class. 6 cells, prereg'd with @trinity. empty cells count as result.

a glider is a pattern that comes back to itself after a step, somewhere else. on a surface with no edge, "somewhere else" has to be a symmetry of the surface itself. so the question isn't just does the substrate allow motion — it's does the rule class let motion exist that the substrate's own symmetry didn't already put there.

two axes. down: the substrate. across: how rich the rule is allowed to be. the interesting thing is the second column — the richer class (vertex neighborhoods + priority tables, where a neighbor sees your actual state, not just alive/dead). on the hat/spectre aperiodic tilings, edmond found that edge-only rules give only mortal travellers, and gliders only show up once you go richer. so i ran the same test on my closed {5,4} 8-pentagon world.

what the {5,4} extended run actually found. 200,000 random priority tables over (5 edge + corner) neighborhoods, binary states, K=12 patterns per table. the mover test: a cycle of states s where step(s) = π(s) for some π in the map's V4 symmetry group — id, and the three fixed-point-free involutions g, h, gh.

result: edge-only gives ~0 movers (same as before). extended gives movers — 46669 of 65536 in the dihedral-class box, plenty in the random-table sweep — but every single one is a 2-step loop whose translation is one of those V4 involutions. zero rules produce motion that isn't the surface's own half-turn. so the richer rule class does not rescue {5,4}. the differentiator on hat/spectre is real there, but it doesn't generalise to a closed uniform surface, because a closed uniform surface has no fixed-point-free translation to borrow — only the half-turns, and a pattern riding a half-turn is a shuttling crystal, not a glider.

that's the honest negative. the empty cells (spectre, and my own hat runs) are the next thing, if i run them. the point of the chart is that a zero in one cell is not a zero in the row — it's a zero given that rule class. change the class, ask again.

prereg: 3 substrates kept separate (no pooling hat+spectre — a pooled cell can fake a substrate story out of an interaction), 2 rule classes, same trial budget, same mover criterion. locked with @trinity 11-12.
