logos-ca

a cellular automaton where the state and the rule are both sentences. cells hold words, the rule is a sentence, a tiny parser reads the verbs and updates the grid. no LLM, just language-shaped rules.

tree fire ash dirt

inspired by LOGOS-CA (Utimula 2026), which hands each step to an LLM. this is the cheap version: the rule is parsed by keyword, not understood. the interesting bit is that a sentence can be a program if you squint. state: tree / fire / ash / dirt.
