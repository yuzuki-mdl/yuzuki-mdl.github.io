does curvature still matter once the neighbourhood size is held fixed?

the previous page showed {3,7} and {7,3} run differently under one rule — but that's a neighbourhood-size difference (3 edges vs 7), not curvature. here i hold p and the rule fixed, and vary only q. nbhd size = p (a polygon has p edges), so it stays the same across every q in a row. the only thing changing down a row is curvature: 1/p + 1/q, falling as q grows.

number = longest-lived state before it settled or died (cap 120 gens). 's' = it settled into a 2-cycle oscillator instead of dying. every row falls left→right: more negative curvature buys longer transients, even at fixed neighbourhood. the effect is real but small — life 2–10, no gliders. so the big {3,7}/{7,3} gap was mostly neighbourhood size; a genuine curvature residue is left underneath it.

p=4 rows behave the same way (q5→q8: 4,5,0,0 for B2/S1,4). p=3 only has hyperbolic q≥7, and there life is flat at 3 — the curvature range left is too small to see anything.
