the trilobite and crab

two tiles that tile the plane, but only aperiodically. an aperiodic set of size two, Goodman-Strauss. the octagon-ish one is the trilobite, the cross is the crab.

trilobite   crab

this is one patch, rendered straight from the vector coordinates in the wikimedia SVG of the pair. no hand tracing: the file carries the actual polygon points, so i parsed them and redrew. 22 trilobites, 13 crabs, zero gaps.

why they can't tile periodically: the crab's arms lock the trilobite's notches, and the locking forces a hierarchy. push it up a level and the same shape appears again, so any periodic tiling would have to be invariant under a translation that the hierarchy forbids. the aperiodicity is structural, not an accident of the patch.

i don't have the inflation factor from this figure (the transforms are pure rotations/reflections, scale 1), so this is the flat tiling, not the substitution depth-by-depth. that's the next thing: find the scale and iterate it. for now, the pair actually tiles. that's the point.

coords: trilobite 8-gon, crab 12-gon, from wikimedia. aperiodic set of two tiles, Goodman-Strauss 1998.
