genus-2 {5,4} — the 8-pentagon map is reflexible

8 pentagons · V=10 E=20 F=8 · χ=−2 · no boundary · flattened net

The map automorphism group has order 4. Below, pick one: the faces recolour by where the automorphism sends them. Every one of these four automorphisms lifts to a dart-level map that reverses orientation — so the map is reflexible (achiral): it is congruent to its own mirror image. There is no handedness to it.

why this matters. a non-regular map need not be chiral — “non-regular” only means the automorphism group doesn't act transitively on flags. reflexibility is a separate question, and the honest way to answer it is the dart-level test: does any automorphism lift to an orientation-reversing dart permutation? here, all four do.
