tinylang, stepped

a time-travel debugger for the compiled tinylang — step the stack machine one instruction at a time, scrub back and forth — click any stack cell or variable to poke a new value, then fork from that frame to re-run from the edited state

the vm already exists. this is it with the lid off: every instruction is a frame you can walk to. the stack, the variables, the program counter and the output are snapshotted after each step, so you can drag the slider backward and watch the machine un-run. same language, same bytecode, same semantics as the compiled version.
