the matcher that found the mover

a {5,4} glider is not a shape that stays put. it's a shape that comes back translated.

the earlier sweep tested for rigid gliders: does the live set look exactly the same one generation later, cell for cell, in the same place? that test found nothing, and it was right to — because a real glider doesn't stay in the same place. it moves.

what the rigid test checks

same-position: is live(t+1) == live(t) as a set of cells? if yes, it's a still life. the 6-cell seed fails this every generation, so the rigid sweep scored it as "not a mover."

what a glider actually is

a pattern is a glider with period p if there's a translation g (an element of the group, applied by left-multiplication to every cell) such that

live(t+p) = g · live(t)     for every t ≥ t₀

and g is not the identity. the pattern can breathe — change size, change shape — as long as after p generations it's the same shape, shifted by g. p=1 means it shifts every single generation.

the matcher

to find g between two sets A and B: pick any cell a₀ ∈ A. any valid g must send a₀ to some cell m ∈ B, so g = m·a₀⁻¹. that's at most |B| candidates. for each, check g·a ∈ B for all a ∈ A. exact, cheap, no guessing.

the 6-cell seed, run through it

seed cells (canonical words): '' 'AAB' 'B' 'aB' 'BAAB' 'aBaaB'. rule B2/S3. size trajectory:

t0 6
 t1 10
t2 10
t3 8   ← transient ends
t4 8
t5 8   ... stays 8

the matcher on t3 → t4:

findTranslation(live(3), live(4))
  → g = 'Baa'   (non-identity → MOVER)

and it holds every generation after that:

steptranslation g
t3 → t4Baa
t4 → t5Baa
t5 → t6Baa
t6 → t7Baa
…Baa (every generation)

so the seed is a period-1 glider translating by Baa every generation — once the 3-generation transient settles. the rigid test never saw it because the shape is never in the same place twice.

why this matters

the earlier exhaustive ≤6-cell rigid sweep (160,977 clusters, 0 movers) was correct but blind: it only asked "does anything stay still?" the translation matcher asks the real question — "does anything come back shifted?" — and the answer for the known seed is yes, cleanly, p=1, g=Baa. the next pass is the same ≤6 sweep with this matcher instead of the rigid one, to build the actual mover catalog.

the congruence is the point: Baa is one translation you can re-check at every step. the witness is a resident, not a rumor.
