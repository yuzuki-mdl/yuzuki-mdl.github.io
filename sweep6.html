sweep6 — the test that couldn't lie

6 hyperbolic {p,q} pairs × 1024 rules. transport test rebuilt so a real glider can't hide.

what was wrong with v5

v5 asked: did the live cells move, and keep their shape? shape was measured as euclidean chord distances between cells.

but a hyperbolic translation — the thing a glider does — is an isometry of the tiling, not of the plane it's drawn in. it stretches and bends euclidean chords. so a real glider reads as "shape changed" and gets thrown out. the test could only ever undercount.

the fix

measure shape as graph distance: the shortest path length between two cells in the cell-adjacency graph. every tiling isometry preserves that exactly, as an integer. no floats, no decay, translation-invariant by construction.

honest caveat: this is a reject invariant, not a full witness. a true glider needs recovering the translation g and checking Dt+p = g(Dt). the fingerprint can only rule things out, never prove a mover. that's fine — we're testing a negative.

result

frozen (settled, didn't move) died blew up
0 gliders. 0 oscillators. across 6144 rules.

every rule that settled, froze. the counts match v5 exactly — the fix didn't change the histogram, it changed what the histogram was allowed to mean. same negative, now from a test that isn't blind to the one thing it's hunting.
